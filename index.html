Por que IsmaCode

Hecho para que
funcione de verdad

IC no es un juguete. Tiene bucles, clases, funciones, canvas 2D, teclado y raton. Todo en tu idioma.

Escribe como hablas

Da igual si escribes mostrar, ponme o dimelo. IC entiende todos.

Juegos desde el dia uno

Pantalla, sprites, teclado, raton, colisiones y 60 FPS. Haz tu primer juego en minutos.

Cero instalacion

Abre el index.html en un navegador y ya. Sin Node, sin Python, sin nada.

Errores que se entienden

Los mensajes de error te dicen la linea exacta y una pista en español sobre que fue mal.

Clases y funciones

Programacion orientada a objetos completa. Clases, metodos, herencia, instancias con nuevo.

Pipes como un pro

Encadena funciones con |>. Codigo limpio, legible y sin variables intermedias.

Sintaxis IC

Menos simbolos,
mas claridad

Compara IC con JavaScript. La misma logica, mucho menos ruido.

IsmaCode IC
# Funcion con bucle
funcion saludo nombre:
  mostrar "Hola, {nombre}!"
fin

lista es ["Ana", "Luis"]
para cada persona en lista:
  saludo(persona)
fin
JavaScript equivalente
// Funcion con bucle
function saludo(nombre) {
  console.log(`Hola, ${nombre}!`);
}

const lista = ["Ana", "Luis"];
lista.forEach(persona => {
  saludo(persona);
});

Leccion 01

Hola mundo

El primer programa de cualquier lenguaje. En IC se escribe en español y sin puntos y coma. Usa mostrar para imprimir texto en pantalla.
